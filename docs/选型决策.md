# 换热器选型决策指南

## 决策流程

### 第一步：确定介质类型

| 介质 | 推荐类型 |
|------|---------|
| 强酸、强碱、溶剂 | PTFE |
| 含固体、高粘度、易结垢 | 螺旋式 |
| 水-水、油-水一般换热 | 板式（垫片式）|
| 高压、高温、承受热膨胀 | 壳板式 |
| VOCs废气冷凝回收 | VOCs冷凝器 |

### 第二步：确定操作条件

- **温度**：是否超过 200°C？ → 壳板式
- **压力**：是否超过 20 bar？ → 壳板式或螺旋式
- **洁净度**：是否有无金属离子析出要求？ → PTFE

### 第三步：考虑维护便利

- 需要频繁开盖清洗？ → 板式
- 空间受限但需要高换热量？ → 壳板式
- 长期连续运转不想频繁维护？ → 螺旋式

---

## 常见组合方案

| 行业 | 换热器 | 配套泵 |
|------|--------|--------|
| 化工生产 | 板式 / 壳板式 | 无轴封磁力泵 |
| 半导体湿式生产 | PTFE | 无轴封磁力泵（内衬型）|
| VOCs治理 | VOCs冷凝器 + 板式 | 气动隔膜泵 |
| 废水处理 | 螺旋式 | 机械密封泵 |
| 食品制药 | 板式（卫生级）| 卫生级离心泵 |
