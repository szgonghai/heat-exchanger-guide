# 板式热交换器 — SRP（舒瑞普）

## 品牌背景

SRP（舒瑞普）是一家专注于板式热交换器的制造商，产品涵盖垫片式和半焊式两大类型，广泛应用于化工、制药、食品、石油、暖通等领域。

## 产品类型

### 垫片式板式热交换器
板片之间通过垫片密封，活动性高。可根据实际工况增减板片数量，调整换热面积，维护和清洗便利。

### 半焊式板式热交换器
两种换热介质之间采用焊接密封，适用于油类与水类之间的换热，承压能力比垫片式更高。

## 工作原理

板式热交换器由一组波纹板片叠合而成，板片之间形成狭窄的流道。两种介质分别在板片两侧流道中流动，通过板片进行热量交换。

波纹板片设计能产生高扰流，提高换热效率，同时使介质分布更均匀。

## 主要特点

- **换热效率高**：波纹板片产生高扰流，相同换热量下体积远小于管壳式
- **体积小、重量轻**：板片叠合结构紧凑
- **灵活调整换热量**：通过增减板片数量适应工况变化
- **清洗便利**：可打开板束进行物理清洗或化学清洗
- **材质选择多**：板片材质有 SUS316L、钛、哈氏合金等；垫片材质有 EPDM、Viton、NBR 等

## 选型注意事项

1. **介质兼容性**：确认板片和垫片材质与介质兼容（腐蚀性介质优先选钛或哈氏合金）
2. **压力与温度**：工况压力和温度须在产品允许范围内，留有安全余量
3. **流速控制**：流速过高会加速板片侵蚀，流速过低则易结垢
4. **水质要求**：水源若硬度高，建议加装软水设备以减少结垢
5. **维修便利**：预留足够的检修空间，便于打开板束进行维护
