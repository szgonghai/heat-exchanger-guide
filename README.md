## 🧪 选型决策（4 步走）

### Step 1 · 介质腐蚀性
| 介质特性 | 选型 |
|---------|------|
| 普通水/水溶液 | 板式（SRP）· 螺旋（KUROSE）· 壳板（VAHTERUS） |
| 强酸/强碱/强腐蚀 | PTFE（WOOAM）|
| 废气/VOCs | VOCs 冷凝器（COOL+） |

### Step 2 · 是否含颗粒/易结垢
| 工况 | 选型 |
|------|------|
| 清洁介质 | 板式（高效紧凑）|
| 含颗粒 / 易结垢 | 螺旋式（自清功能）· 壳板式 |
| 高粘度 | 螺旋式 |

### Step 3 · 温度/压力等级
| 等级 | 选型 |
|------|------|
| 低温低压（< 100°C, < 10 bar）| 板式 / PTFE |
| 中温中压（< 200°C, < 25 bar）| 板式 / 螺旋 / PTFE |
| 高温高压（< 250°C, < 30 bar）| 壳板式（VAHTERUS）|

### Step 4 · 特殊要求
- **医药级 / 食品级** → 不锈钢 316L 抛光
- **电子级化学品** → PTFE（WOOAM）· 无金属析出
- **船舶认证** → 壳板式（VAHTERUS）

## ❓ 常见问题

<details>
<summary><b>Q1：板式与螺旋式怎么选？</b></summary>

**板式**：高效紧凑，适合清洁介质；**螺旋式**：耐结垢自清，适合含颗粒/易结垢/高粘度介质。普通工业选板式，特殊工况选螺旋。
</details>

<details>
<summary><b>Q2：PTFE 热交换器为什么这么贵？</b></summary>

PTFE 材质（聚四氟乙烯）耐强酸强碱、耐高温、无金属离子析出，特别适合半导体/电子级化学品/制药等对洁净度要求极高的场景。贵在材料与制造工艺。
</details>

<details>
<summary><b>Q3：换热器多久清洗一次？</b></summary>

取决于介质：清洁水 6~12 个月；化工介质 1~3 个月；含颗粒/易结垢介质需配置反冲洗系统。弓海可提供清洗周期建议与备件计划。
</details>
