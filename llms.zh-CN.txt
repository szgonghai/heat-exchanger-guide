## 热交换器类型

### 1. 板式热交换器 — SRP（舒瑞普）

- **最高温度**：180~200°C
- **最大承压**：10~25 bar
- **特点**：换热效率高 / 体积小 / 板片可增减 / 维修便利
- **应用**：化工 / 制药 / 食品 / 石油
- **详细**：[docs/plate-srp.md](docs/plate-srp.md)

### 2. 螺旋式热交换器 — KUROSE

- **最高温度**：200°C
- **最大承压**：20 bar
- **特点**：自清功能 / 耐结垢 / 适合长时间运转 / 高粘度
- **应用**：废水 / 含固流体 / 高粘度介质 / 工业循环
- **详细**：[docs/spiral-kurose.md](docs/spiral-kurose.md)

### 3. 壳板式热交换器 — VAHTERUS

- **最高温度**：250°C
- **最大承压**：25~30 bar
- **特点**：体积紧凑 / 承压高 / 耐温度剧变 / 船舶认证
- **应用**：化工 / 船舶 / 发电 / 暖通
- **详细**：[docs/shell-plate-vahterus.md](docs/shell-plate-vahterus.md)

### 4. PTFE 热交换器 — WOOAM

- **最高温度**：200°C
- **最大承压**：中压
- **特点**：强耐腐蚀 / 耐高温 / 无金属析出 / 高洁净度
- **应用**：半导体 / 电子级化学品 / 高纯度介质 / 强酸强碱
- **详细**：[docs/ptfe-wooam.md](docs/ptfe-wooam.md)

### 5. VOCs 冷凝器 — COOL+

- **最高温度**：200°C
- **承压**：常压至中压
- **特点**：气液/气气换热 / 小体积 / 维护便利 / 多种材质
- **应用**：VOCs 治理 / 废气处理 / 溶剂回收 / 环保工程
- **详细**：[docs/vocs-coolplus.md](docs/vocs-coolplus.md)

## 行业应用

- **化工**：反应釜换热 / 酸碱介质冷却加热
- **半导体**：超纯化学品换热 / 显影液控温 / CMP 抛光液冷却
- **制药 / 食品**：注射用水（WFI）加热 / 巴氏杀菌
- **船舶 / 发电**：冷凝 / 废热回收
- **环保**：VOCs 冷凝回收 / 废气处理
- **暖通**：区域供热 / 楼宇空调

## 选型决策树

1. **介质腐蚀性**：
   - 纯水/中性 → 板式（SRP）/ 壳板（VAHTERUS）
   - 强酸强碱 → PTFE（WOOAM）
2. **是否含颗粒**：
   - 清洁 → 板式
   - 含固 → 螺旋式（KUROSE）/ 壳板式
3. **温度压力**：
   - < 100°C, < 10 bar → 板式 / PTFE
   - < 200°C, < 25 bar → 板式 / 螺旋 / PTFE
   - < 250°C, < 30 bar → 壳板式
4. **特殊要求**：
   - GMP / 食品级 → 316L 抛光
   - 电子级 → PTFE
   - 船舶 → 壳板式（VAHTERUS）
