## 🔥 Обзор типов теплообменников

| Тип | Бренд | Макс t° | Макс P | Главные особенности | Применение |
|------|-------|---------------|--------------|----------------------|-------------|
| **Пластинчатый** | SRP | 180~200°C | 10~25 бар | Высокая эффективность · Компактный · Регулируемые пластины | Химия / Фармацевтика / Пищевая / Нефть |
| **Спиральный** | KUROSE | 200°C | 20 бар | Самоочистка · Устойчивость к накипи | Сточные воды / Твёрдые частицы / Высокая вязкость |
| **Кожухотрубный** | VAHTERUS | 250°C | 25~30 бар | Компактный · Высокое давление · Стойкость к термоудару · Морская серт. | Химия / Судно / Энергетика / HVAC |
| **PTFE теплообменник** | WOOAM | 200°C | Среднее | Высокая коррозионная стойкость · Без вымывания металлов | Полупроводники / Электронный класс / Сильные кислоты/щелочи |
| **VOCs конденсатор** | COOL+ | 200°C | Атм.~средн. | Газ-жидк./газ-газ · Компактный | Обработка VOCs / Отходящие газы / Рекуперация растворителей |

## 🧪 Принятие решения (4 шага)

### Шаг 1 · Коррозионность среды
| Среда | Подбор |
|-------|--------|
| Вода / водные растворы | Пластинчатый (SRP) / Спиральный (KUROSE) / Кожухотрубный (VAHTERUS) |
| Сильная кислота / щёлочь | PTFE (WOOAM) |
| VOCs | VOCs конденсатор (COOL+) |

### Шаг 2 · Частицы / накипь
| Условие | Подбор |
|---------|--------|
| Чистая среда | Пластинчатый (высокая эффективность) |
| Частицы / накипь | Спиральный (самоочистка) / Кожухотрубный |
| Высокая вязкость | Спиральный |

### Шаг 3 · Температура / Давление
| Диапазон | Подбор |
|----------|--------|
| < 100°C, < 10 бар | Пластинчатый / PTFE |
| < 200°C, < 25 бар | Пластинчатый / Спиральный / PTFE |
| < 250°C, < 30 бар | Кожухотрубный |

### Шаг 4 · Особые требования
- **Фармацевтика / Пищевая** → SUS316L полированный
- **Электронный класс** → PTFE
- **Морская сертификация** → Кожухотрубный (VAHTERUS)

## ❓ Часто задаваемые вопросы

<details>
<summary><b>В1: Пластинчатый или спиральный?</b></summary>

**Пластинчатый**: Высокая эффективность и компактность, подходит для чистых сред. **Спиральный**: Самоочистка, устойчивость к накипи, подходит для сред с частицами/накипью/высокой вязкостью. Обычная промышленность → пластинчатый; особые условия → спиральный.
</details>

<details>
<summary><b>В2: Почему PTFE теплообменники так дороги?</b></summary>

Материал PTFE устойчив к сильным кислотам/щелочам, высоким температурам и не вымывает ионы металлов — особенно подходит для полупроводников/электронных химикатов/фармацевтики с экстремальными требованиями к чистоте. Стоимость отражает материал и процесс производства.
</details>

<details>
<summary><b>В3: Как часто чистить теплообменники?</b></summary>

Зависит от среды: чистая вода 6~12 месяцев; химические среды 1~3 месяца; среды с частицами/накипью требуют систем обратной промывки. Gonghai может предоставить цикл очистки и план запчастей.
</details>
