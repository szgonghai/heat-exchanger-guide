## 🧪 Decisão de Seleção (4 Passos)

### Passo 1 · Corrosividade do Meio
| Meio | Seleção |
|------|---------|
| Água / soluções aquosas | Placa (SRP) / Espiral (KUROSE) / Casco-Placa (VAHTERUS) |
| Ácido/base forte | PTFE (WOOAM) |
| VOCs | Condensador VOCs (COOL+) |

### Passo 2 · Partículas / Incrustações
| Condição | Seleção |
|-----------|---------|
| Meio limpo | Placa (alta eficiência) |
| Partículas / incrustações | Espiral (autolimpante) / Casco-Placa |
| Alta viscosidade | Espiral |

### Passo 3 · Temperatura / Pressão
| Faixa | Seleção |
|-------|---------|
| < 100°C, < 10 bar | Placa / PTFE |
| < 200°C, < 25 bar | Placa / Espiral / PTFE |
| < 250°C, < 30 bar | Casco-Placa |

### Passo 4 · Requisitos Especiais
- **Farmacêutica / Alimentação** → SUS316L polido
- **Grau eletrônico** → PTFE
- **Certificação naval** → Casco-Placa (VAHTERUS)

## ❓ Perguntas Frequentes

<details>
<summary><b>P1: Placa ou Espiral?</b></summary>

**Placa**: Alta eficiência e compacto, adequado para meios limpos. **Espiral**: Autolimpante, resistente a incrustações, adequado para meios com partículas/incrustações/alta viscosidade. Indústria padrão → placa; condições especiais → espiral.
</details>

<details>
<summary><b>P2: Por que os trocadores PTFE são tão caros?</b></summary>

O material PTFE resiste a ácidos/bases fortes, altas temperaturas e não lixívia íons metálicos — particularmente adequado para aplicações de semicondutores/químicos de grau eletrônico/farmacêutica com requisitos extremos de pureza. O custo reflete o material e o processo de fabricação.
</details>

<details>
<summary><b>P3: Com que frequência limpar os trocadores?</b></summary>

Depende do meio: água limpa 6~12 meses; meios químicos 1~3 meses; meios com partículas/incrustações precisam de sistemas de retrolavagem. A Gonghai pode fornecer ciclo de limpeza e plano de peças de reposição.
</details>
