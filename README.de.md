## 板式热交换器 — SRP（舒瑞普）

### 产品类型
- **垫片式板式热交换器**：活动性高，可随工况增减板片，维修便利
- **半焊式板式热交换器**：两种介质间采用焊接密封，适合油类与水类换热

### 主要特点
- 换热效率高（板片波纹设计增加扰流）
- 体积小、重量轻
- 可根据操作条件增减板片数量，灵活调整换热量
- 清洗方便（可打开清洗或化学清洗）
- 多种材质板片与垫片可选，适配不同介质

### 规格参考

| 参数 | 垫片式 | 半焊式 |
|------|--------|--------|
| 换热面积 | 定制 | 定制 |
| 最大承压 | 约 10-25 bar | 约 10-25 bar |
| 操作温度 | -20°C ~ +180°C | -20°C ~ +200°C |
| 板片材质 | SUS316L、钛、哈氏合金 | SUS316L |
| 垫片材质 | EPDM、Viton、NBR | — |
| 认证 | CE | CE |

## PTFE热交换器 — WOOAM

### 产品类型
- **壳管式 PTFE 热交换器**：加热/冷却高腐蚀性介质
- **盘管式 PTFE 热交换器**：适合高洁净度流体

### 主要特点
- PTFE（聚四氟乙烯）材质，极强耐腐蚀性
- 耐多种强酸、强碱、有机溶剂
- 耐高温可达约 +200°C
- 材质不与介质反应，不析出金属离子
- 适用于半导体、电子级化学品、高纯度介质

### 规格参考

| 参数 | PTFE热交换器 |
|------|------------|
| 材质 | PTFE / PFA 内衬 |
| 操作温度 | -20°C ~ +200°C |
| 承压 | 常压至中压 |
| 适用介质 | 强酸、强碱、溶剂、高纯度化学品 |
| 认证 | 半导体行业适用 |

## VOCs冷凝器 — COOL+

### 主要特点
- 气液或气气换热，用于VOCs废气冷凝回收
- 独特气体导流信道设计，液体与气体充分接触换热
- 小体积，适合空间受限的场合
- 维护清洗便利
- 多种材质可选，适配不同废气成分

### 适用场景
- VOCs废气冷凝回收（溶剂回收）
- 化工、涂装、印刷等行业废气治理
- 废气预处理（冷却减容）
- 与洗涤塔、活性炭吸附等设备配套

## Auswahlkriterien

### 1. 看介质
- 强酸强碱 → PTFE热交换器
- 含固体或高粘度 → 螺旋式（自清）
- 水-水或油-水换热 → 板式（垫片式）
- 高压高温 → 壳板式

### 2. 看温度
- 中低温（<200°C） → 板式、螺旋式
- 高温（>200°C） → 壳板式、PTFE（看具体型号）
- 超低温 → 壳板式

### 3. 看洁净度
- 半导体 / 电子级 → PTFE（无金属析出）
- 一般工业 → 板式 / 螺旋式
- 卫生级（制药/食品） → 板式（卫生级认证）

### 4. 看维护便利性
- 需频繁清洗 → 板式（可开盖清洗）
- 免维护长期运转 → 螺旋式（自清）
- 空间受限 → VOCs冷凝器（小体积）
