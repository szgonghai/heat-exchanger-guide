## 🧪 Auswahlentscheidung (4 Schritte)

### Schritt 1 · Medienkorrosivität
| Medium | Auswahl |
|--------|---------|
| Wasser / wässrige Lösungen | Platte (SRP) / Spirale (KUROSE) / Schale-Platte (VAHTERUS) |
| Starke Säure / Base | PTFE (WOOAM) |
| VOCs | VOCs Kondensator (COOL+) |

### Schritt 2 · Partikel / Verschmutzung
| Bedingung | Auswahl |
|-----------|---------|
| Sauberes Medium | Platte (hohe Effizienz) |
| Partikel / Verschmutzung | Spirale (selbstreinigend) / Schale-Platte |
| Hochviskosität | Spirale |

### Schritt 3 · Temperatur / Druck
| Bereich | Auswahl |
|---------|---------|
| < 100°C, < 10 bar | Platte / PTFE |
| < 200°C, < 25 bar | Platte / Spirale / PTFE |
| < 250°C, < 30 bar | Schale-Platte |

### Schritt 4 · Besondere Anforderungen
- **Pharma / Lebensmittel** → SUS316L poliert
- **Elektronikgrad** → PTFE
- **Marine-Zertifizierung** → Schale-Platte (VAHTERUS)

## ❓ FAQ

<details>
<summary><b>F1: Platte oder Spirale?</b></summary>

**Platte**: Hohe Effizienz und kompakt, für saubere Medien. **Spirale**: Selbstreinigend, verschmutzungsresistent, für partikelhaltige/verschmutzungsanfällige/hochviskose Medien. Standardindustrie → Platte; Sonderbedingungen → Spirale.
</details>

<details>
<summary><b>F2: Warum sind PTFE-Wärmetauscher so teuer?</b></summary>

PTFE-Material widersteht starken Säuren/Basen, hohen Temperaturen und gibt keine Metallionen ab — besonders geeignet für Halbleiter/Elektronik-Chemikalien/Pharma-Anwendungen mit extremer Reinheitsanforderung. Die Kosten spiegeln Material und Fertigungsprozess wider.
</details>

<details>
<summary><b>F3: Wie oft Wärmetauscher reinigen?</b></summary>

Medienabhängig: sauberes Wasser 6~12 Monate; chemische Medien 1~3 Monate; Partikel-/Verschmutzungsmedien benötigen Rückspülsysteme. Gonghai kann Reinigungszyklus und Ersatzteilplan bieten.
</details>
