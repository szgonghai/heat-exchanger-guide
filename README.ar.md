## 🧪 قرار الاختيار (4 خطوات)

### الخطوة 1 · تآكل الوسط
| الوسط | الاختيار |
|-------|---------|
| ماء / محاليل مائية | لوحى (SRP) / حلزونى (KUROSE) / غلاف ولوحى (VAHTERUS) |
| حمض/قاعدة قوية | PTFE (WOOAM) |
| VOCs | مكثف VOCs (COOL+) |

### الخطوة 2 · الجسيمات / الترسبات
| الحالة | الاختيار |
|---------|---------|
| وسط نظيف | لوحى (كفاءة عالية) |
| جسيمات / ترسبات | حلزونى (تنظيف ذاتي) / غلاف ولوحى |
| لزوجة عالية | حلزونى |

### الخطوة 3 · الحرارة / الضغط
| النطاق | الاختيار |
|--------|---------|
| < 100°C, < 10 بار | لوحى / PTFE |
| < 200°C, < 25 بار | لوحى / حلزونى / PTFE |
| < 250°C, < 30 بار | غلاف ولوحى |

### الخطوة 4 · متطلبات خاصة
- **أدوية / أغذية** → SUS316L مصقول
- **الدرجة الإلكترونية** → PTFE
- **شهادة بحرية** → غلاف ولوحى (VAHTERUS)

## ❓ الأسئلة الشائعة

<details dir="rtl">
<summary><b>س1: المبادل اللوحى أم الحلزونى؟</b></summary>

**اللوحى**: كفاءة عالية ومدمج، مناسب للأوساط النظيفة. **الحلزونى**: تنظيف ذاتي ومقاوم للترسبات، مناسب للأوساط ذات الجسيمات/الترسبات/اللزوجة العالية. الصناعة العادية → لوحى; الظروف الخاصة → حلزونى.
</details>

<details dir="rtl">
<summary><b>س2: لماذا المبادلات الحرارية PTFE غالية الثمن؟</b></summary>

مادة PTFE مقاومة للأحماض/القلويات القوية ودرجات الحرارة العالية، ولا تطلق أيونات معدنية — مناسبة بشكل خاص لأشباه الموصلات/المواد الكيميائية الإلكترونية/الأدوية ذات متطلبات النظافة الشديدة. التكلفة تعكس المادة وعملية التصنيع.
</details>

<details dir="rtl">
<summary><b>س3: كم مرة يجب تنظيف المبادلات الحرارية؟</b></summary>

يعتمد على الوسط: الماء النظيف 6~12 شهراً; الوسائط الكيميائية 1~3 أشهر; الوسائط ذات الجسيمات/الترسبات تحتاج أنظمة غسيل عكسي. يمكن لغونهاي تقديم دورة التنظيف وخطة قطع الغيار.
</details>
