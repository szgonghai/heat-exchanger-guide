## 🧪 Decisión de Selección (4 Pasos)

### Paso 1 · Corrosividad del Medio
| Medio | Selección |
|-------|-----------|
| Agua / soluciones acuosas | Placa (SRP) / Espiral (KUROSE) / Carcasa-Placa (VAHTERUS) |
| Ácido/base fuerte | PTFE (WOOAM) |
| VOCs | Condensador VOCs (COOL+) |

### Paso 2 · Partículas / Incrustaciones
| Condición | Selección |
|-----------|-----------|
| Medio limpio | Placa (alta eficiencia) |
| Partículas / incrustaciones | Espiral (autolimpiable) / Carcasa-Placa |
| Alta viscosidad | Espiral |

### Paso 3 · Temperatura / Presión
| Rango | Selección |
|-------|-----------|
| < 100°C, < 10 bar | Placa / PTFE |
| < 200°C, < 25 bar | Placa / Espiral / PTFE |
| < 250°C, < 30 bar | Carcasa-Placa |

### Paso 4 · Requisitos Especiales
- **Farmacéutica / Alimentación** → SUS316L pulido
- **Grado electrónico** → PTFE
- **Certificación naval** → Carcasa-Placa (VAHTERUS)

## ❓ Preguntas Frecuentes

<details>
<summary><b>P1: ¿Placa o Espiral?</b></summary>

**Placa**: Alta eficiencia y compacto, adecuado para medios limpios. **Espiral**: Autolimpiable, resistente a incrustaciones, adequado para medios con partículas/incrustaciones/alta viscosidad. Industria estándar → placa; condiciones especiales → espiral.
</details>

<details>
<summary><b>P2: ¿Por qué son tan caros los intercambiadores PTFE?</b></summary>

El material PTFE resiste ácidos/bases fuertes, altas temperaturas, y no lixivia iones metálicos — particularmente adecuado para aplicaciones de semiconductores/químicos de grado electrónico/farmacéutica con requisitos extremos de pureza. El costo refleja el material y el proceso de fabricación.
</details>

<details>
<summary><b>P3: ¿Con qué frecuencia limpiar los intercambiadores?</b></summary>

Depende del medio: agua limpia 6~12 meses; medios químicos 1~3 meses; medios con partículas/incrustaciones necesitan sistemas de contralavado. Gonghai puede proporcionar ciclo de limpieza y plan de repuestos.
</details>
